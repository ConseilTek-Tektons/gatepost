# Gatepost role-based access control

Delegated administration separates directory management, application integration, adaptive policy, session termination, factor reset, signing-key rotation, event export, audit, and access administration.

Security administrators do not automatically receive break-glass ownership. Application administrators manage integrations but not directory-wide policy. Help desk can perform scoped recovery without rotating keys or editing access rules. Auditors read configuration and authentication evidence without mutation. Unknown groups receive `viewer`.
